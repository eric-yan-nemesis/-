# 本地词典与 C1/C2 学习资料

这份指南把“在 Mac 上查词”和“给 LexiScope 提供数据”分别说明。所有链接指向原发布者或本项目的实际 GitHub 页面。下载到云工作区的文件不会自动出现在你的 Mac；请点击 HTTPS 下载地址或运行下载助手。

## 推荐组合

| 资料 | 包含什么 | CEFR 等级 |
| --- | --- | --- |
| ECDICT 简明英汉增强版 | 中文释义、部分英文定义、词形与词频；有 MDX 和欧路版 | 无 C1/C2 标签，考试/词频标签不等于 CEFR |
| Octanove Vocabulary Profile C1/C2 v1.0 | 词头、词性、C1/C2 和少量义项备注 | 明确给出词条等级；不是 Cambridge EVP，也未核实每次出现的语境 |
| Open English WordNet 2025 | 英文义项、定义、同义关系和部分例句 | 无中文、无 CEFR 标签 |

不存在已经在本次检查中确认、可免费整本下载并自动导入本网站的剑桥英汉 CEFR 词典。剑桥/EVP适合作为等级及用法的学习参考，商业离线版本和数据库接入需要分别确认授权。牛津5000能辅助到C1，不应当作完整C2库。

## 在 Mac 上直接查词

1. 安装支持 MDX 的词典阅读软件，例如从[欧路词典官网](https://www.eudic.net/)选择 Mac 版本。
2. 下载原作者发布的 [ECDICT MDX 压缩包](https://github.com/skywind3000/ECDICT/releases/download/1.0.28/ecdict-mdx-28.zip)，或者选择 [欧路版压缩包](https://github.com/skywind3000/ECDICT/releases/download/1.0.28/ecdict-eudic-28.zip)。版本和格式说明见[原作者发布页](https://github.com/skywind3000/ECDICT/releases/tag/1.0.28)。
3. 解压后，按阅读软件的“词典管理/导入本地词典”操作。需要的配套资源应一起保留。

这是本地释义词典；导入阅读器不会自动增加 C1/C2 过滤功能。ECDICT 的收词面较广，也有罕见词、专名和专业词，并非每条都适合优先背诵。

## 获取适合网站使用的原始数据

- [ECDICT 英汉 CSV 固定版本](https://raw.githubusercontent.com/skywind3000/ECDICT/ab22ad36302cafc6349a050e2b60894855208055/ecdict.csv)：本次下载为 66,009,548 字节，770,611 条记录。CSV 在浏览器中可能显示为文本，可用“链接另存为”保存。
- [Octanove C1/C2 CSV 固定版本](https://raw.githubusercontent.com/openlanguageprofiles/olp-en-cefrj/d4e45b75b38f27b30dfc5c44d8c571aec7e7092f/octanove-vocabulary-profile-c1c2-1.0.csv)：2,136 条原始记录、1,955 个不同词头；不是2,136个不同单词。去掉完全重复记录后是2,108条。
- [Open English WordNet 2025 官方 JSON ZIP](https://github.com/globalwordnet/english-wordnet/releases/download/2025-edition/english-wordnet-2025-json.zip)：9,986,555 字节；包含128,009个词头，部分义项有例句。没有中文和等级。

## 用下载助手生成双语 C1/C2 学习表

本项目的 `download-dictionaries.command` 会下载固定版本 ECDICT 和 Octanove 及许可说明，校验文件，并在本机 `dictionaries-local/` 中生成 `C1C2_英汉词汇.csv`。词典下载约63MiB，需要联网；后续查阅生成的表格无需联网，也无需模型API。

需要 Python 3.9 或更新版本。Mac 上打开终端，输入 `bash `（保留空格），将项目中的 `download-dictionaries.command` 拖到终端，按回车。等待显示完成。

生成表保留等级、词性、来源备注、中文/英文释义及来源说明。跨来源按词头连接不代表各个义项已经对齐；中文缺失会保留空值，不会编造翻译；无来源例句不会自动生成。**目前只生成可查阅的数据文件，尚未把整本 ECDICT 或 WordNet 接入网站分析流程。** 网站现有内置CEFR识别仍照常使用。
