# LexiScope 个人词典：使用与原始资料下载

现在的网站使用 **Octanove × Wordset** 个人词典。完整文件已经随项目附带，并接入阅读分析与“我的词典”页面；不必另外安装 ECDICT、MDX 阅读软件或其他字典，也不必先联网重建。

## 已经包含哪些资料

| 内容 | 来源与处理方式 |
| --- | --- |
| C1/C2 等级、词性、少量义项备注 | Octanove Vocabulary Profile C1/C2 v1.0，保留原始记录 |
| 英文义项和定义 | Wordset Dictionary，按同词头及来源明确列出的拼写连接 |
| 英文用例 | 保留 Wordset 原始内容；可能是完整句子或短语，无用例时留空 |
| 中文学习注释 | 应用为 17 个词头另行编写的注释，不属于上述两份词典原文 |
| 可选上下文解释 | 用户启用后由 AI 辅助生成，单独标注，不改写原词典 |

个人词典覆盖 **1,955 个原始词头**，其中 **1,844 个有英文义项**、**1,060 个有至少一条来源用例**。详细数量、匹配方式与局限见 [个人词典说明](../data/PERSONAL_DICTIONARY.md)。这些是公开来源资料的组合，不是 Cambridge English Vocabulary Profile，也不代表所有 C1/C2 英语词汇的完整清单。

**等级只来自 Octanove。** 同一个词有多种词性和义项时，不能把词头的 C1/C2 标记套到所有 Wordset 义项上。界面保留等级记录与义项的区别，并提示语境仍需核对。没有查到某词，也不代表它低于 C1。

## 在 Mac 上使用

1. 下载并解压完整 LexiScope 项目，保留 `app`、`static`、`data` 等文件夹及其结构。
2. 按 [README](../README.md) 安装依赖、启动服务器；也可以在终端运行 `bash run-mac.command`。需要 Python 3.12 或更新版本。
3. 在 Mac 浏览器中打开已经运行的本机网站，点击导航中的“我的词典”。
4. 输入词条原形，例如 `meticulous`、`alleviate`、`cast` 或 `bona fide`，查看等级候选、原始英文义项、用例和来源。
5. 点击“下载我的词典 JSON”保存完整文件。原文件也在 `data/lexiscope_dictionary.json`，旁边有 `.sha256` 校验值。

项目依赖安装完毕后，离线查词、分析和导出不需要联网或 API 密钥。AI 解释需要另外配置后端密钥并明确开启；默认不添加模型估计等级，只有另行勾选额外估计才会显示这类候选，且始终标为估计。用户上传的文章、AI 生成的句子都不会成为 Wordset 原始用例。

JSON 是网站使用的数据文件，不是可以双击安装的 Mac 应用。云工作区的文件也不会自动出现在你的 Mac；请使用项目实际发布的 HTTPS 下载地址获取项目，而不要把云端内部路径当作本地地址。

## 可选：从固定来源重新构建

正常使用无需执行这一步。它用于核验来源、恢复数据，或重新生成随项目附带的同一版本词典。

从项目根目录运行：

```bash
python tools/build_personal_dictionary.py
```

Mac 也可以运行：

```bash
bash download-dictionaries.command
```

这个入口现在只构建 **Octanove × Wordset**，不会下载 ECDICT。它使用已附带的 Octanove 原始 CSV，必要时下载约 **17 MB** 的固定版本 Wordset ZIP，校验摘要后提取定义与用例。Wordset 原资料默认缓存到被 Git 忽略的 `dictionaries-local/wordset-source/`。

已经下载该固定版本归档时，可离线复用：

```bash
python tools/build_personal_dictionary.py --wordset-archive /path/to/wordset.zip
```

也可以把同样的参数传给 Mac 入口：

```bash
bash download-dictionaries.command --wordset-archive /path/to/wordset.zip
```

默认更新 `data/lexiscope_dictionary.json`、对应 `.sha256` 文件及 `data/wordset/` 中的来源许可。重建前应备份自行修改过的数据；可用 `--output` 和 `--license-dir` 指定其他输出位置。重建完成后重新启动网站，使内存缓存读取新文件。下载和构建不执行上游仓库代码，不关闭 TLS 或校验值验证。

## 来源和许可需要一起保留

- **Octanove Labs / Open Language Profiles**：采用 CC BY-SA 4.0；原始资料和署名见 [data/SOURCES.md](../data/SOURCES.md)。
- **Wordset, Inc. 及贡献者**：采用 CC BY-SA 4.0，继承的 Princeton WordNet 3.0 内容同时保留其许可、署名和免责声明。完整来源许可已附在 [data/wordset/LICENSE](../data/wordset/LICENSE)。
- 组合、选取、去重和结构整理的结果按 CC BY-SA 4.0 共享，并保留底层 Princeton WordNet 条款；复制个人词典时，应同时保留来源、授权链接、许可文本和改动说明。
- 中文学习注释和可选 AI 内容各自标注出处；它们不是两份原资料提供的中文释义，也不能当作已经核实的词义分级。

## 其他资料：仅供另行选择

下列资料**不属于当前个人词典，也没有接入它的分析流程**。使用现有网站不需要下载这些资料。

| 可选资料 | 可提供什么 | 限制 |
| --- | --- | --- |
| [ECDICT](https://github.com/skywind3000/ECDICT) | 大型英汉释义、词形和词频资料 | 没有 CEFR 标签；词频或考试标签不能转成 C1/C2 |
| [Open English WordNet](https://github.com/globalwordnet/english-wordnet) | 英文定义、义项关系和部分用例 | 不是本项目当前使用的 Wordset 固定版本；无中文和 CEFR |
| [Cambridge Dictionary](https://dictionary.cambridge.org/) / [EVP](https://www.englishprofile.org/wordlists/evp) | 学习词义和参考等级 | 不应默认存在可免费整本下载、可再分发并可直接导入的离线库 |

旧版 `tools/download_dictionaries.py` 仍可由有需要的用户手动运行，下载 ECDICT 与 Octanove 并生成独立的本地英汉学习表；它不替换网站的个人词典。ECDICT 作者仓库提供 MIT LICENSE，同时说明历史资料来源多样，不能把仓库级许可当作每条释义权利已经单独审计的保证。该旧工具会另行下载约 63 MiB 文件，正常使用本项目无需运行。
