# 项目需求：CEFR C1 及以上英语词汇高亮工具

## 项目目标

开发一个网页应用，识别用户提供的文档或文本中属于欧洲语言共同参考框架（CEFR）C1 和 C2 等级的英语词汇，对这些词汇进行高亮，并根据上下文提供中文注释。

## 核心需求

1. 支持用户粘贴英语文本，以及上传 DOCX 和 PDF 文件。
2. 从上传的文档中提取英语文本。
3. 识别被划分为 CEFR C1 或 C2 等级的单词和短语。
4. 在法律和技术条件允许的情况下，使用可靠的词汇等级参考来源。
5. 考虑上下文，区分同一个词的不同含义。
6. 在原文中高亮显示目标词汇。
7. 展示词汇表，包含以下信息：单词或短语、CEFR 等级、词性、符合上下文的中文含义、英文释义以及例句。
8. 支持导出带注释的 DOCX 或 PDF 文件，以及词汇清单。
9. 正确处理词形变化和重复出现的词汇。
10. 对不确定的词汇等级分类进行明确标注，不将其呈现为已经核实的事实。

## 技术偏好

- **前端：**HTML、CSS 和 JavaScript。
- **后端：**如可靠的文档处理需要后端，则使用 Python。
- **DOCX 处理：**使用 `python-docx`。
- **PDF 处理：**使用 PyMuPDF，并在适当的情况下支持 OCR（光学字符识别）。
- **人工智能：**使用通过 API 调用的语言模型，进行上下文理解并生成中文注释。
- **安全：**验证上传文件，限制文件大小，保护 API 凭据，并避免不必要地保留用户文档。

## 开发要求

首先实现一个可以运行、仅接受粘贴文本的原型。在基本的词汇识别和高亮流程能够正常工作之后，再加入 DOCX 和 PDF 文档处理功能。

说明系统架构，提供完整、可运行的代码，列出安装步骤，并编写覆盖以下方面的测试：词汇等级准确性、词形匹配、文档格式，以及文件导出行为。

除非某个词的 C1 或 C2 等级分类有合适的参考来源支持，或已经明确标注为估计结果，否则不得宣称该词属于 C1 或 C2。
